# Испытания на целевой плате

Использовать второй независимый передатчик/приёмник с известными настройками.
В тестовый payload включать идентификатор радио, sequence number и контрольную
сумму данных, чтобы видеть потери до попадания в программную RX-очередь.
Для анализа CS/IRQ/BUSY полезен логический анализатор. На испытательном ядре
включить lockdep и KASAN, если позволяют ресурсы платы.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Один SX1262, обычные GPIO | Успешный SET_CONFIG, RX и TX с совпадающим payload |
| E22 через TCA9554 | Корректные CS/reset/BUSY/RXEN/TXEN и отсутствие одновременных CS |
| Восемь радио на одной SPI | Восемь устройств; независимые PHY-конфигурации; один TX в эфире |
| Две группы TX из разных процессов | Группы последовательны; фреймы внутри группы не перемежаются |
| Два IRQ во время высокого общего DIO_INT | Оба события обслужены, даже без второго фронта |
| RX по 1, 254 и 255 байт, два подряд | Нет искусственного reset/SetRx между корректными кадрами |
| Поток 10000 пар 255-байтовых фреймов | Подсчёт sequence gaps, измерение максимальной задержки IRQ до чтения RAM |
| Переполнение RX-очереди | Растёт rx_dropped; TX-результаты сохраняются |
| Не читать 32 TX-результата | Следующая заявка возвращает EAGAIN с O_NONBLOCK; чтение освобождает место |
| Частичное завершение группы и ошибка TX | frames_sent отражает подтверждённые TX_DONE; остаток не отправляется |
| CRC/header error | Пакет не попадает в read; последующий корректный принимается |
| Ложная преамбула без HEADER_VALID | Возврат в RX по короткому таймауту преамбулы, без ожидания полного пакета |
| HEADER_VALID без DONE/error | Возврат в RX по отдельному таймауту payload с учётом LDRO |
| Повторные PREAMBLE/HEADER IRQ без завершения | Дедлайн текущей стадии не продлевается |
| RX_DONE появился к истечению дедлайна, но IRQ потерян | Опрос регистра обрабатывает пакет и снимает дедлайн до решения о recovery |
| Implicit RX без HEADER_VALID | Достаточный таймаут на полный кадр фиксированной длины |
| Обрыв IRQ при работающем SPI | Растёт polled_irqs; по тишине выполняются soft/hard recovery |
| Нет трафика более двух интервалов watchdog | Soft recovery, затем hard recovery; RX после этого работает |
| Длинная преамбула/SF12, узкая BW | Watchdog не обрывает допустимый кадр раньше расчётного дедлайна |
| BUSY одного модуля удерживается высоким | Ограниченный timeout, reset виновника; очередь остальных продолжает работу |
| close во время группы | Текущая передача остановлена reset; остаток группы отменён |
| unbind во время read/TX, затем bind | Нет use-after-free/hang; ожидающие fd разбужены; новое устройство работает |
| Неверные ioctl/длины/зарезервированные поля | Ошибка без частичного TX и без повреждения состояния |
| E22 и внешний PA на нескольких мощностях/частотах | Измеренные мощность и ток соответствуют DT-профилю; при необходимости таблица исправлена |

Потери при недопустимо коротком межкадровом интервале должны быть измерены
отдельно: программная очередь не устраняет ограничение аппаратного буфера
SX1262 и задержки доступа через GPIO-расширитель.
